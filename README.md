One text message from your future self to your present self — a warning
about autocorrect, 15 years too late to prevent, just in time to laugh at.

## Entry

> Future you. Turn off autocorrect NOW. In 2041 it changes 'ducking' to the other word in a text to my boss's boss. Twice. I still work there. Barely.

148 characters, one line.

## How it works

`main.py` writes the entry to `entry.txt` inside the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), as UTF-8 bytes with no trailing
newline.

## Run

```sh
python3 main.py
```
